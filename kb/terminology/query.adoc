---
title: Запрос (query)
type: docs
---

// tag::definition[]
Действие, предназначенное для получения сведений о состоянии системы или выводов на их основе.
Должен быть безопастным — запрос не должен менять состояние системы, поэтому его должно быть возможно вызывать несколько раз не опосаясь нежелательных побочных эффектов.
// end::definition[]
